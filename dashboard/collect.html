Collecte du parc

Déployez le collecteur sur les machines du réseau pour inventorier automatiquement

Méthode 1 — PowerShell direct

Depuis cmd.exe (Invité de commandes) :

powershell -NoProfile -ExecutionPolicy Bypass -Command "$env:SRV='http://SERVEUR_IP:5000'; iex (irm ($env:SRV+'/collect.ps1'))"

Depuis PowerShell :

$env:SRV='http://SERVEUR_IP:5000'; iex (irm ($env:SRV+'/collect.ps1'))

Le script va s'exécuter et envoyer les données automatiquement.

Méthode 2 — Fichier .BAT

Téléchargez et exécutez ce fichier batch sur chaque machine :

@echo off
set SRV=http://SERVEUR_IP:5000
powershell -NoProfile -ExecutionPolicy Bypass -Command "$env:SRV='%SRV%'; iex (irm ($env:SRV+'/collect.ps1'))"
Télécharger .BAT

Configurez la variable SRV dans le fichier avant distribution.

Méthode 3 — GPO / Déploiement masse

Pour déployer via GPO, script de logon ou outil de déploiement :

powershell -NoProfile -ExecutionPolicy Bypass -Command "$env:SRV='http://SERVEUR_IP:5000'; iex (irm ($env:SRV+'/collect.ps1'))"

Vous pouvez aussi prédéfinir la variable SRV via GPO (variable d'environnement système).

Instructions détaillées

Étape 1

Prérequis

PowerShell 5.1+ sur Windows 10/11, serveur accessible depuis les clients (pare-feu ouvert port 5000).

Étape 2

Remplacez l'IP du serveur

Dans les commandes ci-dessus, remplacez SERVEUR_IP par l'adresse IP réelle de ce serveur.

Étape 3

Exécutez sur la machine cible

Ouvrez PowerShell en administrateur et exécutez la commande. Le collecteur va analyser la machine et envoyer le rapport.

Étape 4

Vérifiez dans le dashboard

Les données apparaîtront dans les onglets Tableau de bord, Machines et Catalogue.

Notes de sécurité

• Le collecteur est read-only — il ne modifie rien sur la machine cible.

• Aucune donnée personnelle n'est collectée (uniquement inventaire logiciel/matériel).

• La communication se fait en HTTP. Pour du HTTPS, placez un reverse proxy (Nginx, Caddy).

• Les machines doivent pouvoir joindre le port 5000 du serveur.
